Advanced Tool by Rakib (Y-box)

This is an advanced tool with several functionalities for network and system operations. The tool provides options for:

1. IP Info Checker
2. Phone Number Info
3. Ping a Website
4. My IP Info
5. YouTube Video Downloader
6. Device Info
7. Port Scanner
8. Website Status Checker
9. Hash Generator (MD5, SHA256)
10. File Downloader
11. Base64 Encode/Decode
12. Fake Identity Generator


TERMUX INSTALLATION 
★ pip install pytube phonenumbers requests




The tool allows users to:
- Check IP address info.
- Look up phone number details.
- Download videos from YouTube.
- Perform network diagnostics like pinging and port scanning.
- Hash input data for security purposes.
- Download files from direct URLs.
- Encode and decode in Base64.
- Generate fake user identities.

Requirements:
- Python 3.x
- Install required libraries using:
  pip install pytube phonenumbers requests

How to use:
1. Clone this repository.
2. Install dependencies.
3. Run the main Python script (main.py).
4. Follow the interactive menu to perform various tasks.
